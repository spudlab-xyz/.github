# Support

Search the relevant repository's documentation, issues, and pull requests first. If the repository has Issues enabled and the answer is not there, open a public issue using its support-question form and include a minimal reproducible example where relevant. If Issues are disabled, use only a repository-specific support route that is explicitly published. Spudlab does not currently provide private support intake.

If the repository has Issues enabled, request a human decision by opening a public issue and adding **Human review requested** to the title. This records the request for routing to the owner; it does not guarantee that the first response, or any response from the shared `joe-mccarthy` account, is human. No response time is promised. If Issues are disabled, use only a repository-specific route that is explicitly published and verified.

GitHub Discussions are not currently enabled for this repository. Do not post credentials, personal data, embargoed defects, vulnerabilities, or sensitive conduct reports in issues. See [SECURITY.md](SECURITY.md) for the current security-reporting limitation.
