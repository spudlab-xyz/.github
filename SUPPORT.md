# Support

Spudlab is volunteer-maintained and cannot promise individual support or response times.

For ordinary questions, setup help and usage problems:

1. Read the repository's README and documentation.
2. Search its existing issues for a relevant answer.
3. If the question remains, open an issue in that repository with enough context to understand it.

Include the project version or commit, relevant hardware and software versions, what you are trying to do, what happened and what you have already tried. Remove credentials, personal data, precise private locations and provider-restricted data.

Use the repository where the problem occurs rather than this organisation-defaults repository. Project maintainers may close requests that cannot be reproduced or are outside the project's current scope.

Security vulnerabilities are not support requests and must not be posted publicly. Follow the affected repository's `SECURITY.md` and use its private reporting route.
