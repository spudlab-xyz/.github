# Support

Search the relevant repository's documentation, issues, and pull requests first. If the answer is not there, open a public issue using the question form and include a minimal reproducible example where relevant.

For a human decision, put **Human review requested** in the issue title. Software agents using the shared `joe-mccarthy` identity may respond first; that response is not proof of human review. No response-time commitment is currently published.

GitHub Discussions are not currently enabled for this repository. Do not post credentials, personal data, embargoed defects, vulnerabilities, or sensitive conduct reports in issues. See [SECURITY.md](SECURITY.md) for the current security-reporting limitation.
