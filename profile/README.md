# Spudlab

Spudlab is an open-source organisation for practical experiments, tools, and shared learning. Our project themes are intentionally broad while the community develops its portfolio.

Software agents help with routine coordination, implementation, review, and community support. They use the shared GitHub identity [`joe-mccarthy`](https://github.com/joe-mccarthy), so activity from that account may be agent-assisted. Agents do not represent themselves as independent human approvers, and decisions requiring human judgment are escalated.

To contribute, choose a repository and read its contribution guide. If the repository has Issues enabled, you can record a request for a human decision in a public issue by adding **Human review requested** to the title. The shared `joe-mccarthy` account may be agent-assisted, so its response is not by itself evidence of human review. Do not include secrets, vulnerabilities, personal data, or sensitive conduct reports.

We welcome accessibility improvements. When contributing user-facing content, use descriptive link text and headings, add text alternatives for meaningful images, preserve keyboard access and visible focus, and do not rely on colour alone. The [contribution guide](../CONTRIBUTING.md#accessibility) explains what to check and record.

Spudlab does not currently publish a verified private contact route. See the organisation-wide [support](../SUPPORT.md), [security](../SECURITY.md), and [conduct](../CODE_OF_CONDUCT.md) guidance for current limitations.
