# Spudlab

**Community-first, open-source tools for science. Building software and hardware for collecting, sharing and understanding data.**

Spudlab aims to make scientific data easier to gather, preserve, inspect and use. Weather is the starting point, not a limit on the subjects Spudlab may explore.

## What we intend to build

The first projects are planned and in early development:

- a weather history server that ingests observations from external providers and people's own weather stations, stores historical data and exposes it through a REST API; and
- open weather station hardware and firmware designed to connect to that server.

The server is intended for observations and historical data, not weather forecasting. Project repositories will be linked here when they are public and ready to use.

## How we work

Spudlab is committed to open development, scientific integrity and reproducible methods. Data sources, units, timing, transformations and limitations should be traceable. Experimental work should be labelled honestly, and mistakes should be corrected visibly.

Read the [scientific principles](https://github.com/spudlab-xyz/.github/blob/main/docs/SCIENTIFIC_PRINCIPLES.md), [governance](https://github.com/spudlab-xyz/.github/blob/main/GOVERNANCE.md) and [licensing policy](https://github.com/spudlab-xyz/.github/blob/main/docs/LICENSING.md).

## Contribute

Useful contributions include code, documentation, testing, accessibility improvements, scientific review, calibration work, hardware experiments and specific feedback. Please read the [contribution guidance](https://github.com/spudlab-xyz/.github/blob/main/CONTRIBUTING.md) before starting substantial work. For ordinary help, see the [support guidance](https://github.com/spudlab-xyz/.github/blob/main/SUPPORT.md).

Spudlab is currently founded, built and maintained by one person. Contributions are welcome, and the project's processes can grow with its community without pretending that community already exists.
