# Licensing policy

This document records Spudlab's preferred approach. It is not legal advice and does not replace the licence in any repository.

## New software projects

Apache License 2.0 is the preferred default for new Spudlab software. It is a permissive licence: it permits use, modification, distribution and commercial reuse subject to its terms, and includes an explicit contributor patent grant. It does not require every downstream modification to be published.

Every repository must contain its own actual licence. GitHub does not inherit a `LICENSE` file from the organisation's `.github` repository. A central policy expresses intent; it does not automatically license every repository, relicense existing work or resolve ownership of contributions.

Existing licences, third-party notices and contributor rights must be respected. Changing an existing project's licence requires a specific review of copyright ownership, contribution terms and compatibility; it must never happen silently.

## Other material

Hardware designs, documentation, datasets, firmware and third-party data can need different or multiple licensing decisions. Choose terms deliberately for each repository and identify material covered by different terms.

External provider data does not become Apache-2.0 merely because Spudlab software downloads, stores or processes it. Provider terms, database rights, privacy, attribution and redistribution limits must be reviewed separately.

Software licensing does not imply endorsement by Spudlab or unrestricted use of its names, logos or other branding. Apache-2.0 itself does not grant trademark permission beyond the limited use described in its terms.
